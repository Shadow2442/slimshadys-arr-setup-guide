# Blocked Language Markers Template

Use this as a starting list for title-term penalties or release-profile blocks.

## Normal German/English Lanes Should Penalize

| Marker | Why |
| --- | --- |
| `VFQ` | French Canadian marker. |
| `VFF` | French marker. |
| `TRUEFRENCH` | French-only signal. |
| `FRENCH` | French-only signal unless intentionally scoped. |
| `EN-TR` | English/Turkish, not German. |
| `TR-EN` | Turkish/English, not German. |
| `TURG` | Turkish group/marker pattern. |
| `HEBREW` | Hebrew-only signal unless intentionally scoped. |

## Caution

Do not blindly block original-language media in scoped lanes. Korean, Chinese, and Japanese can be valid when the title belongs in that lane.
